# Topic 1: Variables, Arguments & Exit Codes

## 🎯 Objective
Learn how to define variables, accept positional arguments (`$1`, `$2`), supply safe default fallbacks, and use exit codes in Bash scripts.

---

## 🛠️ Files in this Topic
1. [`practice.sh`](file:///mnt/c/Myfolder/MyProjects/shell-scripting-projects/topics/topic_01_variables_and_arguments/practice.sh): Runnable demo script showing variables and positional parameters.
2. [`exercise.sh`](file:///mnt/c/Myfolder/MyProjects/shell-scripting-projects/topics/topic_01_variables_and_arguments/exercise.sh): Simple hands-on exercise for you to modify and run.

---

## 🚀 How to Run

```bash
# Make sure scripts are executable
chmod +x practice.sh exercise.sh

# Run practice without arguments (it will use defaults)
./practice.sh

# Run practice with arguments
./practice.sh auth-api 5

# Run your exercise
./exercise.sh
```
